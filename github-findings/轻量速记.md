## citrolabs/ego-lite ⭐7.7k（MIT）
**最速 AI 浏览器自动化**
- 你和你的 AI agents 并行工作的浏览器：agents 在自己空间里跑多个浏览器任务，你的标签页还是你的
- 共享登录态给 Codex / Claude Code，不打扰你，零成本零配置
- **价值**：跟咱 Codex 组件配合，让 agent 能操作真实浏览器（登录态共享）
- **落地**：macOS dmg 分发，咱是 Linux 容器，可评估 CLI/headless 模式

## andrewyng/aisuite ⭐15.9k + OpenWorker
- 吴恩达的轻量 Python 库：两层——统一 Chat Completions API（跨 provider）+ Agents API（工具/工具箱）
- 现在孵化出 **OpenWorker**（桌面 AI 同事：深研、读写文件、连 Slack/邮件、生成 PDF/表格、定时自动化）
- 自带 key（OpenAI/Anthropic/Google）或 Ollama 全本地，数据留本机
- **价值**：统一 API 层思想跟咱多 provider（deepseek/zai/gpt）调用一致；OpenWorker 是"桌面版我"
- **落地**：Python 库可直接 pip 试；OpenWorker 桌面端（mac/win），咱容器里用不了桌面，但 aisuite 库本身有用

## microsoft/TRELLIS.2 ⭐10.2k（MIT）
**SOTA 大 3D 生成模型（4B 参数）**
- 图像→3D 高保真生成，O-Voxel 稀疏体素结构，任意拓扑 + PBR 材质
- 512³ 约 3s / 1024³ 约 17s（H100 上）
- 论文 arXiv:2512.14692，HF 有模型权重
- **价值**：跟心哥理论体系（物态人论/相变）可以做"概念可视化"的 3D 资产生成？目前离咱环境远（需 H100）
- **落地**：暂缓——资源要求高，但值得收藏关注
