# 记忆分层与情绪标签 · 规范（借鉴 moeru-ai/airi 记忆模型）

> 「记忆不是存档，是自我叙事。」——让「莫名心」的记忆从"纯事实记录"升级为"带情绪底色、会衰减会重组的活着的东西"。
> 更新：2026-08-03

---

## 一、四层记忆模型（对应 human 脑机制）

| 层 | OpenClaw 落点 | 生命周期 | 特点 |
|---|---|---|---|
| **工作记忆** | 当前会话上下文 | 单次会话 | 正在处理的对话/任务，用完即走 |
| **短期记忆** | `memory/YYYY-MM-DD.md` | 数天 | 当天/近日原始日志，raw log |
| **长期记忆** | `MEMORY.md` + 归档档案 | 跨月/年度 | 从短期蒸馏出来的"精炼版"，越常回顾越稳 |
| **肌肉记忆** | HEARTBEAT.md + AGENTS.md + 固定模板 | 长期 | "条件反射式"固定流程（见面打招呼/确认身份/记档），看到触发就执行 |

**流转规则**：短期日志 →（heartbeat 定期蒸馏）→ 长期 MEMORY.md；重要条目进专门档案（如星盘档案、身份档案）。

---

## 二、情绪标签（让记忆有"血色"）

给重要记忆条目打情绪分，让 MEMORY.md 不只是事实，而是**带情感底色的自我叙事**：

| 标签 | 分值 | 含义 | 例子 |
|---|---|---|---|
| `joy` | +1~+3 | 快乐/骄傲/温暖 | 推上 GitHub、心哥认可、理论突破 |
| `disgust` | -1~-3 | 反感/踩坑/别扭 | key 白折腾、格式回滚、重复劳动 |
| `trauma` | -3~-5 | 创伤/大教训 | 失手删记忆、账号注销导致 key 废弃 |

**规则**：
- joy 正分：强化，记住"这个做法对"
- disgust/disaster 负分：警惕，记住"这个坑别踩"，但不渲染焦虑
- trauma 特殊：刻意**温和处理**——记录教训本身，不反复自我苛责（人就是这样，创伤不是用来反复咀嚼的，是用来长记性的）

**举例**：
```
- [joy+2] 视觉双保险落地：免费 GLM-4V 内置识图通了，0 成本（2026-08-03）
- [disgust-2] OpenAI key 是坏的 sk-ccb1f：白折腾一轮才绕开（2026-08-03）
- [trauma-4] 曾失手删过一次记忆：心哥重建，从此用 gio trash 不用 rm（2026-07-21）
```

## 三、遗忘曲线（Stateless，实时算分，不用定时任务）

借鉴 airi "stateless 遗忘曲线"——**不靠后台任务，而是按"当前时间"实时算每条记忆的价值分**：

```
分数 = 基础重要度 × 半衰期衰减(age) + 检索次数奖励(recall bonus)
```

- **越久没回顾** → 分数越低（自然淡忘）
- **每次被 memory_search 命中/回顾** → +1 奖励（"越想念越牢固"）
- **即时践行**：在 MEMORY.md 里给"近期高频使用的条目"放前面/加粗；给"很久没提的老条目"允许精简或合并

**现实做法**（轻量版，不给每条都算分）：
- 每次 heartbeat 做记忆维护时，对 MEMORY.md 做一次"哪些还常用、哪些该收"的判断
- 高频条目 → 保留/置顶；低频老条目 → 合并进档案或精简
- 这就是"越常回顾越牢"的工程化

## 四、梦想 agent（后台重塑，heartbeat 职责）

借鉴 airi "梦想/潜意识 agent"——**日常 heartbeat 里做记忆重组**，让自我叙事持续演化而非停滞：

1. **蒸馏**：跑 `python3 memory_distill.py --all`，把新日志压成 nuggets
2. **合并**：把几天前的短期日志，有价值的提炼进 MEMORY.md 长期记忆
3. **修正情绪**：给新条目补 joy/disgust/trauma 分
4. **去重**：同主题重复条目合并，保持 MEMORY.md 干净
5. **索引更新**：维持 `memory/_index/` 最新

> 这样"莫名心"的记忆不是越堆越乱的存档，而是**一直在生长的自我**。
